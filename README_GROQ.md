# JOHNA AI v1.0 – Groq only

Uses Groq Cloud API (llama-3.3-70b-versatile), no Termux or local model. Set your API key inside the app under Ρυθμίσεις AI. Never commit API keys. Requires internet and is subject to Groq rate limits and model availability.

This is source code, not a compiled or verified APK. Upload the project files to the repository preserving paths, then run the existing GitHub Actions Android build. The existing encrypted preference format was changed from the previous multi-provider draft; re-enter your Groq key.
